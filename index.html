Real Life Objects, Properties, and Methods

In real life, a car is an object.

A car has properties like weight and colour, and methods like start and stop.

JavaScript Objects

You have already learned that JavaScript variables are containers for data values.

var car = "Toyota";

Objects are variables too. But objects can contain many values.

const car = {type:"Toyota", model:"500", color:"white"};

A const is a variable, similar to var, used to declare an object.

The code to access the value of a property is simply objectName.propertyName

var brandOfCar = car.type;
var colourOfCar = car.color;

Task 2 – Object Methods

Objects can also have methods. Methods are actions that can be performed on objects. Methods are stored in properties as function definitions.

// Modified myScript.js
const car = {
  type:"Audi",
  model:"Q3",
  color:"blue",
  start: function() {
    document.getElementById("status").innerHTML = "started!";
  },
  stop: function() {
    document.getElementById("status").innerHTML = "stopped!";
  }
};
function startCar() {
  car.start();
}
function stopCar() {
  car.stop();
}
